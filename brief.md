The standard version number format must be X,Y,Z.where X,Y and Z are non negative integers without leading zeros. X represents the MAJOR version when make incompatible API changes.Y the MINOR version when add functionality in backward compatible manner. Z the PATCH version when make backward compatible bug fixes.

## AI
RAG (Retrieval Augmented Generation) is an AI framework that connects LLMs (Large Language Models ) with external search and database. By grounding the AI language skills in your specific data, it generates answers that are more accurate, up-to-data, and relevant.RAG helps reduce incorrect answers and fabrications (hallucinations) by grounding the language models response in verified , external and up to date sources documents rather than relying solely on its static training memory.

## Mobile
IOS App Transport Security (ATS) enforce that all network connections made by an app use secure protocols and strong cryptographic standards.if app tries to call a plain HTTP , connection blocked ATS immediately denies the network request. Also, console error the system will cancel the request and print a clear text blocking error message in the Xcode console. The networking API returns an error to your application (typically an ⁠NSURLErrorDomain⁠ error indicating that a secure connection could not be made or that the resource could not be loaded because ATS requires HTTPS).
